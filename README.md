# FeedSense

FeedSense is an AI-powered research platform for analyzing personalized social media recommendation systems.

## Vision

Build an open-source platform that helps researchers and users understand recommendation algorithms, content diversity, and behavioral patterns while respecting user privacy.

## Features (Planned)

- Android data collection
- AI-powered content classification
- OCR
- Speech-to-text
- Dashboard
- Diversity metrics
- Research mode

## Tech Stack

- Kotlin
- Python
- FastAPI
- PyTorch
- React
